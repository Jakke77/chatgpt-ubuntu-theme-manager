# ChatGPT Ubuntu Theme Manager 1.2.4 · Veriyö

[Lataa Ubuntu-deb](https://github.com/Jakke77/chatgpt-ubuntu-theme-manager/raw/refs/heads/packages/v1.2.4/chatgpt-ubuntu-theme-manager_1.2.4_all.deb)

```bash
sudo apt install ./chatgpt-ubuntu-theme-manager_1.2.4_all.deb
```

Sulje ja avaa manageri uudelleen. Valitse **Veri Aika · Veriyö** ja ota teema
käyttöön. **Vaihda myös taustakuva** valitsee Otava-kuvan. Hiillos on mukana
teeman taustakuvakansiossa. Päivitys säilyttää aiemmin valitun teeman.

Vanhemmalle managerille: [Veriyo.ctm-theme.zip](Veriyo.ctm-theme.zip) tai
[JSON-paletti](Veriyo.theme.json), tuonti **Tuo teema…** -painikkeella.
Väripaketti käyttää vanhan managerin omaa taustakuvapohjaa.

[SHA256SUMS](SHA256SUMS) · [Tarkistustiedot](QA.json).

55 testiä ja puretun debin tiedostot sekä oikeudet tarkistettu. Tämän julkaisun
GTK 4 / GNOME -ulkoasua ei kokeiltu rakennusympäristössä, josta kirjastot puuttuvat.
Runtimevaatimukset: GTK ≥ 4.18, libadwaita ≥ 1.6 ja Ubuntu/GNOME/Yaru.
